# Nature Article 当前要求核查

核查日期：2026-11-06。适用期刊：Nature 主刊 Article，非 Nature Methods 期刊。

| 项目 | 当前规则及本稿处理 |
|---|---|
| Methods 篇幅 | 通常不超过约 3,000 词；必要时可更长，仍须精炼。不是无条件不限长度。本稿保留复现所需模型、筛选、误差构造及控制检验，不为增加篇幅保留统计讲义。 |
| Methods 图表 | Methods 本身不放图表；重要方法图表安排为 Extended Data，并在 Methods 引用。 |
| Extended Data | 图和表合计最多 10 项，刊于在线 HTML 和 PDF 末尾；v68 仅列五项目录，未声称已完成全部扩展数据。初投可并入单一稿件文件。 |
| 主文 | 初投允许合理格式弹性；典型 6 页 Article 为约 2,500 词及 4 项适度大小图表。此为版面指导，不能等同于必须填满的字数。 |
| 标题与图注 | 标题不超过 75 字符，本稿 73。初投指南图注少于 250 词，另一格式页使用 300 词上限，本稿采用更严格的 250 词。 |
| 引文顺序 | 按文本、表/图注、Methods 和 Extended Data 的首次出现连续编号。Methods 新引用继续主文编号。 |
| 数据和代码 | 必须有真实可执行的评审访问安排。数据存储库为优先路径；相关地球与环境科学数据有存储库要求。不能把占位 DOI 或仅有论文 PDF 的 GitHub 目录当成复现数据存储库。 |
| 作者声明 | 本篇作者、通讯作者、贡献、基金和利益声明须由作者确认；PRL 的现成名单和基金不能自动证明适用于本篇。 |
| AI | 如实披露实际用途，作者承担内容责任。不能未经确认声称作者已逐项验证所有分析。 |
