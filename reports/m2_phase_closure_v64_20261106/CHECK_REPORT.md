# v64 历史模板相位核查与新版稿件报告

## 1. 研究问题、数据与授权边界

本轮解决 v63 提出的 28° 相位冲突，并按该结论整理主文、图序及可审阅材料。输入冻结为 2026 年 P3–P8 六期、2,905 个非重叠 600 s 平均、1,737,073 个名义源成员、35 个 BJT 日。它们是同一钟比对的重复测量，不是 2,905 个独立实验；六期重抽样也有小簇数和独立性假设。2025 调试数据仍不进入跨年电平联合分析。

原始计数器、筛选掩码、权重、修正值、现行物理系数均未修改。本轮没有依据潮汐残差排点，也没有优化历史模板的相位、振幅或时间移动。完成的是明确授权的冻结数据诊断与稿件整理，没有启动新的正式全数据拟合、专家派发、自动审批或第三轮专家评审。

## 2. 两套模板放到同一天文相位坐标

采用 C=a+ib，y=f[a cos(θ)+b sin(θ)]，θ=V+u；arg(C) 正方向表示滞后。时间统一由 BJT 转 UTC，pyTMD FES 天文参数使用 TT−UTC=69.184 s。在共同 360,000 点理论时间网格上投影，与钟数据拟合分开进行。

| M₂ 分量 | cos 系数 | sin 系数 | 幅度 | 滞后角 |
|---|---:|---:|---:|---:|
| 固体潮 | 2.921211 | 1.788630 | 3.425299 | 31.478737° |
| 现行负荷 | 0.884301 | 1.106259 | 1.416262 | 51.362515° |
| 现行总模板 | 3.805512 | 2.894889 | 4.781455 | 37.260592° |
| 历史负荷 | 0.922666 | -1.143741 | 1.469509 | -51.106570° |
| 历史总模板 | 3.843877 | 0.644889 | 3.897599 | 9.523845° |

系数与幅度单位为 10⁻¹⁸，相应基函数还含 nodal factor。**历史/现行总 M₂ 幅度比 0.81514916，相位差 -27.73674716°。** 加入所有 18 个负荷分潮及 5 个长周期项后为 0.81537111、−27.75572928°；投影遗漏小分潮不能解释约 28° 的差别。现行固体潮与负荷 M₂ 矢量夹角 19.8838°。

证据：`verification/COMMON_PHASE.json`、`v63_13_coefficients.csv`、`full_23_coefficients.csv`。

## 3. 历史文件是什么，以及错误在哪里

本次被废弃的是 18 分潮、位势型 PREM 负荷时间序列及其相加总序列，**不是**旧频率比论文中另一个八分潮、位移型负荷近似。两条历史链不混同。

| 属性 | 源码/文件核查结果 |
|---|---|
| 分潮 | M2、S2、N2、K2、K1、O1、P1、Q1、2N2、mu2、nu2、l2、t2、r2、eps2、lambda2、j1、m3 |
| 海洋输入 | FES2022b 非外推高度网格；空间复系数采用 exp(−iG) 滞后约定 |
| 物理量 | 负荷势：直接势、诱导势及位移贡献组合 1+k′−h′，不是仅把垂直位移乘 g |
| Love 数 | Han–Wahr PREM 0–696 阶表，延拓至 40,000 阶，末 30% 余弦 taper 与 Kummer 尾项；CE 一阶约定 h′₁=−0.288，k′₁=0 |
| 坐标 | 武汉 30.529°N、114.357°E；上海 31.130°N、121.570°E，为既有理论输入坐标，并非本轮认证的钟跃迁点 |
| 差分 | D=(P_SHA−P_WUH)/c²；c=299792458 m/s |
| 正确时间配对 | f Re[D exp(+iθ)]，等价于 f Re[D* exp(−iθ)] |
| 存储历史序列 | Re[D* exp(+iθ_old)]：共轭之后没有反转时间指数；并缺少 f |
| 历史 θ_old | 现有 Schureman helper 在每个 60,000 点块起点取值，块内按既有固定分潮角速度推进 |

直接使用存量复系数和源代码定义的候选，没有拟合观测，也没有连续扫描相位/时间。四种候选全部记录如下，误差相对存储的历史负荷序列：

| 系数 | nodal factor f | RMS / 10⁻¹⁸ |
|---|---|---:|
| D | 不加 | 2.219640634 |
| D | 加 | 2.247320156 |
| D* | 不加 | 1.54719×10⁻¹³ |
| D* | 加 | 0.104215883 |

第三行在全部 360,000 点上的 RMS 为 **1.55×10⁻³¹ 分数频率**，最大差约 1.12×10⁻³⁰。另用实三角表达 abs(D) cos(θ_old−arg D) 独立重算，RMS **1.56×10⁻³¹**。这定位了存储波形的时间构造；原始 shell 命令尚未恢复，不能把数值构造复现写成恢复了原始运行日志。

证据：`phase_audit.py`、`verify_temporal.py`、`SOURCE_DEFINED_RECONSTRUCTION.json`、`MODEL_INPUTS.json`。废弃登记：`LEGACY_TEMPLATE_RETIREMENT.json`。旧 CSV 不删除、不改名、不覆盖。

## 4. 独立核查现行时间相位

调用现成 PyFES 2026.5.2 的 restricted M₂ predictor，限制为同一个已给定 M₂ 复势系数，不加入平衡潮或推断分潮；检查完整 8,760 小时历表。与 pyTMD 3.0.9 当前时间合成相比：

- M₂ 角差最大 0.01402597°；
- 波形 RMS 2.3465e-22，最大差 3.35997e-22 分数频率；
- PyFES 零输入、单分潮、线性与缩放自检通过。

这是独立天文时间实现的交叉核查，复用了空间负荷系数。**不是重新认证全球负荷卷积、台站测量或全部理论系统误差。** 证据：`TEMPORAL_INDEPENDENT_CHECK.json`、`PYFES_REQUEST.json`、`PYFES_RESPONSE.json`、`PYFES_M2_COMPARISON.csv`。

## 5. 严格区分“源码错误”与“数据排除”

> **醒目提示：不能写“历史模板已被观测相位以 5% 水平排除”。** 废弃的成立依据是上面的时间合成错误，而不是挑选较有利的统计检验。

保持现行 N₂、近 12 h、日潮、固定余项和六期常数完全相同，仅在共同 M₂ 平面比较物理预测。测得坐标 (0.997728, −0.068032)；历史单位预测在此平面为 (0.721485, −0.379378)。六期、64 种符号的条件 restricted-wild 检验：

| 问题 | 双侧 P |
|---|---:|
| 现行单位点 | 0.96875 |
| 历史单位点 | 0.0625 |
| 现行方向，幅度自由，仅检验正交分量 | 0.625 |
| 历史方向，幅度自由，仅检验正交分量 | 0.09375 |

名义删日 F 椭圆会排除历史单位点，但删期条件检验在 5% 下没有。因此未挑选删日结果来制造“相位排除”。本轮是回顾性、模型条件诊断，无多重性校正；不是随机化实验的精确检验。局部误差传播的响应相位为 −3.90°、工作 SE 约 10.17°，不冒充校准置信区间。

先前历史相位对 (1.166,0.609) 同时更换了其他分潮及 nuisance 列；本轮将其与同 nuisance 的比较区分，不能直接把两套原生坐标当同一平面。

另一个重要统计区别已改入稿件：期内重置日项后的固定相位标量 M₂ 为 0.820±0.200，其标量 P(0)=0.03125；释放 M₂ 正交分量后的**联合** P(0)=0.125。摘要和 Fig. 2 图注将“不排除零”明确限定为后一联合检验。名义删日椭圆和删期条件检验不同，不混称同一个置信域。

## 8. 尚存的物理范围与作者事项

本轮关闭了“历史生成链导致约 28° 差异”问题，没有将现行模型总不确定度设为零。空间卷积共用既有系数；其高阶 taper/Kummer 尾项与近场误差未在本轮重新评定。静态源码还显示 h′/k′ 在末端趋零，而 Kummer 基线系数采用 7.224；0 阶实现与文档的逐字描述也并不完全等同。共同 0 阶常量在相同海洋网格的站间差中会抵消，但这不构成高阶/近场误差上界。保留该边界，不能因时间相位核查通过而替整个空间核背书。

台站跃迁点坐标、未监测钟/实验室支路的时间变化、大气负荷、全链时序认证等仍受原稿的证据限制约束。它们不从被废弃模板的 0.179 推导，也不能由当前 A 接近 1 自动证明无误。
