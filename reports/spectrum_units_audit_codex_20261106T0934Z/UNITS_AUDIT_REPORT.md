# 引力势谱密度纵轴验算

**结论：没有发现旧图的数量级换算错误。** 原图横轴用 µHz，纵轴用每 Hz 的谱密度，两者可以同时使用，但容易把密度峰高误读为势振幅。新增等价图把纵轴也写成每 µHz；数值恰好缩小一百万倍，物理谱、峰位和相对高低完全不变。旧图和原数据均保留。

## 换算与实际读数

钟比观测约定为 `y = −ΔW/c²`，故 `S_W = c⁴ S_y`；负号不改变功率。这里 `c = 299792458 m/s` 是精确值，`c⁴ = 8.07760871306249×10³³`。存储表中的 y 数值以 `10⁻¹⁸` 为单位，所以功率需乘 `10⁻³⁶`，这一因子在旧代码中已正确计入。

| 同一局部峰 | 频率 / µHz | 原势PSD / (m⁴ s⁻⁴ Hz⁻¹) | 等价势PSD / (m⁴ s⁻⁴ µHz⁻¹) |
|---|---:|---:|---:|
| M₂ 附近 | 22.361111 | 190441.1528 | 0.19044115 |
| S₂ 附近 | 23.147151 | 68022.4592 | 0.06802246 |

因 `df_Hz = 10⁻⁶ df_µHz`，要使 `S df` 不变，必须有 `S_per_µHz = 10⁻⁶ S_per_Hz`。自动验算使用 Astropy 单位系统完成这一转换，并检验频带积分在更换坐标单位前后不变。

**PSD不是振幅，也不是振幅谱密度。** 势振幅单位是 m² s⁻²，PSD 单位是 m⁴ s⁻⁴ Hz⁻¹，ASD 单位是 m² s⁻² Hz⁻¹/²。M₂附近旧图约 1.90×10⁵ 的读数不表示势振幅为 1.90×10⁵ m²/s²。该频点的单频正弦扫描振幅约 0.478 m²/s²；它包含采样与其它频率的泄漏，不能替代联合物理模型的分潮幅度。

## 独立验算结果

1. 先将实际观测逐点转成 SI 势值，再用完整54段指示变量及单频正余弦直接最小二乘；不调用旧扫描函数，也不先从旧PSD乘 c⁴。21个频点分别计算观测、固定理论和两者时域之差，共63项对照；与旧谱的最大相对差为 **7.29×10⁻¹¹**。
2. 单独构造软件校准夹具：4096点、间隔600 s、振幅0.45 m²/s²、频率在一个FFT格点上的正弦。解析一侧PSD峰高、SciPy周期图和独立最小二乘都得到 **248832 m⁴ s⁻⁴ Hz⁻¹**；谱积分为 **0.10125 m⁴ s⁻⁴**，等于振幅平方的一半。这说明小势振幅与大的每Hz密度峰高并不矛盾。夹具没有混入观测或研究图。
3. 核查 `10⁻³⁶`、`c⁴`、PSD/ASD、采样间隔、样本数和 Hz/µHz 因子；输入哈希保持一致。两个既有CSV在低功率位置的最大相对差为4.99×10⁻¹³，属于有限精度传播；首次过紧阈值的失败已留档。

## 归一化的适用范围

原算法定义 `P = ΔRSS/N`，一侧标称600秒LS密度为 `600×ΔRSS`。因此从保存的 `P` 到势PSD的总因子为 `600×3299×10⁻³⁶×c⁴ = 15988.8186866`。完整均匀采样时与标准一侧周期图一致；没有把全年缺测时间填成零，也没有用拟合补点。

**保留的技术边界：这是间断记录的标称LS密度。** 54段常数投影与采样窗改变频率响应，不能直接把整个扫描谱的积分当连续全年方差，也尚未将其标定成可与任意设备噪声底直接比较的平稳噪声PSD。这与引力势单位换算是否正确是两个问题。图轴现明确写为 “Nominal potential PSD”。

橙线在时域扣除同一采样上的固定单位理论预测，再做相同扫描；不是两个PSD相减，也没有重估潮汐振幅。它可以称为指定模型下的残余噪声谱，同时仍可能含模型误差和未解释信号。
