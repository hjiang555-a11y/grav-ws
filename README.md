## 1. 项目研究什么

武汉Yb与上海Sr光钟通过1,350 km光纤比较频率。历史工作侧重高精度Yb/Sr绝对比值；当前Nature稿侧重在太阳日干扰下测量月球半日潮引力势变化。材料显示沿海上海的预测海洋负荷贡献较大，但当前稿不声称独立测出负荷。[PROJECT_PROFILE：E02、E08、E27]

## 2. 拥有哪些材料

递归元数据盘点共 **30,963 个普通文件、18,427,597,316 字节（18.43 GB）**，含 Git、虚拟环境与自动记录。排除所有隐藏路径及 __pycache__ 后，科研/项目文件为 **1,551 个、15,770,230,766 字节（15.77 GB）**。这是文件逻辑大小之和，不是磁盘实际占用。

主要材料包括71份实验拍频/链路TXT（夏季25、链路29、新数据17）、1份潮汐Excel、9份DOCX、108份CSV、163份PDF、15份BibTeX、102份LaTeX、186份Python、6份Shell、2份MATLAB，以及76份约13.76 GB的FES压缩格网。科研文件中还有166 PNG和19 SVG；PDF同时包含论文、文献和图件，不能把163个全部算作论文。具体筛选口径、文件大小和位置见 PROJECT_MAP。

## 4. 当前数据和分析体系

原项目分数据、研究分支、论文文档三层。原始计数器记录主要位于 clock/data 与 newdata；海潮图集在 data/fes2022；PRL源码主要为 clock、clock_ratio；探索和候选复现在 research；稿件和图件在 paper。接入目录不改变这些路径。

环境声明要求Python 3.12，原 .venv 配置记录3.12.3。uv.lock、本地包元数据和历史运行清单不是完全同一状态；R未被项目配置识别。源码中存在GPU、模型数据、TeX和外部技能工具依赖，并有按源码目录写输出的行为。因此不能把旧脚本直接从这里调用视为安全接入。[PROJECT_MAP]

## 6. 哪些仍然不清楚

- **数字认证**：V14采用作者报告的0.77±0.19，不是本次独立测得；旧V7数值不再作验收真值。
- **时长和组身份**：546 h、552.132 h及另一候选重建552.356944 h各有不同来源/选择，未统一。
- **PRL版本**：冻结manifest比值末位…7160，现有PDF…7166，有后续修正报告；不能混为一个认证版本。
- **实验事实**：同步精度、实时BBR补偿、分频极性、温度完整性及操作组日志尚待核对。
- **模型/误差**：完整势模型验证、S2差异、误差覆盖与相干干扰边界尚未闭合。
- **发布与文献**：稿件实际投稿状态、所有引用/DOI核验、最终作者与数据代码声明为UNKNOWN。

这些缺口来自现有材料或本次静态检查，详见RESEARCH_STATUS。未读取的材料不能视为不存在。

## 7. 如何继续使用工作站

以本目录为后续任务入口，先读AGENTS和档案，再明确选择PRL追溯、V14证据补齐或其他研究任务。当前最具体的新稿入口是原项目 `paper/nature/lunar-independent-v14-20261103/README.md`，原项目根README和AGENTS的版本路由存在滞后。

本阶段未创建数据链接、脚本、环境、结果子目录或共享交接副本。以后在获得具体分析授权后，再在工作站内建立独立的代码、处理数据和结果空间；只读访问原始输入，先审查写出路径和依赖。不要在原项目运行run_all、uv sync、GPU卷积、发布或同步脚本。论文投稿、公开上传和推送均需人工明确确认。
