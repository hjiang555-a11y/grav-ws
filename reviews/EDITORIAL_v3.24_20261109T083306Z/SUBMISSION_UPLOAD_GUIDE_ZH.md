# Nature初次投稿分立文件包｜v3.24

对应当前作者定稿及依据11月8日指导重写的最新版cover letter。此包用于人工上传，不代表已经投稿。论文及图件内容未修改；旧版本不混入投稿目录。

## 上传对照

| 目录 | 文件与用途 | 选择方式 |
|:--|:--|:--|
| 01_Cover_letter | 最新cover letter，PDF / Word / Markdown | 上传PDF或Word其中一种；共两页，含六位推荐审稿人 |
| 02_Main_manuscript | 主稿PDF与可编辑Word | 含摘要、正文、Methods、参考文献、Table 1、主图和ED图表图注；Word保留可编辑公式与表格。两种是相同稿件的备选格式 |
| 03_Main_figures | Figure_1.pdf至Figure_4.pdf | 四张主图各一个独立PDF，使用当前稿件实际引用的版本 |
| 04_Extended_Data | 8张ED图和2张ED表，TIFF | 共10个独立图像文件。图注在主稿末尾；不要把图注重新叠入图像 |
| 05_Supplementary_Information | SI PDF | 原定稿7页，单独上传 |
| 06_Optional_extracts | Table 1、主图图注、ED图注的PDF/Word/Markdown；审稿人CSV | 按投稿系统需要选用；表与图注已包含在主稿，不重复追加到主稿。审稿人CSV便于填写系统，非论文补充数据 |
| 07_Reading_copies | 完整40页阅读PDF；ED的独立PDF备选 | 作者/编辑阅读备用；如系统选择合并稿，可用完整PDF。避免把同一ED的TIFF与PDF当作两个不同项目上传 |

Methods属于主稿，没有从主稿中删除或拆成另一个正文版本。Table 1是可编辑表，2张ED表按现有图像提供。所有独立图像均不附加图注，图注保留于文字文件。
