# 统一 Primary 处理所需输入

本次不是再申请执行授权。作者已明确授权统一处理；目前缺的是与稿件 Primary 对应的真实计算输入和实现。

## 最小可用交付

优先提供原 Primary 工程目录及运行入口。若已有导出包，至少包含：

1. **统一筛选后的记录与成员账本**：54 段逐秒数据的文件/行身份、时间、段/operating group/period/campaign、保留掩膜、瞬态和端点排除原因。实际保留总秒数从账本汇总，544 h 作为原文约数核对，不作为必须凑到的目标。
2. **同一筛选上的三角滤波**：1,200 s 窗口、600 s 步长，窗口中心、边界/缺失处理与归一化；每个输出的成员及权重，或可精确重建这些权重的代码。有效曝光按成员账本计算，重叠滤波窗不能重复计时。
3. **对齐的物理模板**：Primary 使用的直接势固体潮、海洋负荷、八分潮和固定余项；包括月球/近12 h/日潮组、相位移90°模板、相应单位与时标。数据与模板必须经过同一滤波。
4. **原拟合和误差入口**：等权/54段常数的设计、残差连续运行分组、200次残差平移、按日删除和bootstrap的实现、日期边界、随机种子与既有输出。已保存的滤波结果足以启动部分拟合；若缺实际滤波算子，仍不能正确完成白噪声传播与新的扫描设计。

## 接入后运行顺序

- 核对成员数、总时长、滤波行数、日历跨度、54段及五个campaign，建立唯一输入清单。
- 复现完整模板、半日带、三组和自由相位拟合；比较原文报告值，保留差异，不调参追数。
- 在同一处理输出上生成幅度谱、联合单频拟合、条件谱、双向扣除、相关性和旁瓣诊断。试验正弦也应用同一筛选和滤波算子。
- 使用对应估计器及滤波后噪声协方差重新生成信噪比表。统一处理并不意味着把组响应的误差冒充自由相位单分潮的误差。
- 图、表、摘要和正文全部从结果清单更新；检查同名量的时长、单位、幅度/功率、单频/组响应及误差口径；重排引用和图表编号；编译新支线。

## 数学上的必要一致性

记逐秒白噪声协方差为 D，实际选样和滤波的线性映射为 F，滤波后拟合矩阵为 H，则系数协方差使用

\[
C_{\beta,\mathrm{white}}=H F D F^{\mathsf T}H^{\mathsf T}.
\]

这是线性传播关系，不是本轮已执行的计算结果。相邻三角窗可共享输入，不能直接沿用独立600秒均值的对角协方差。日删除或残差重采样还需要原实现对“日”和“连续运行”的定义。保留原统一处理方法，不自行选另一套实现来追平旧数字。
